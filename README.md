# Portafolio académico · David Martínez

**Repo:** https://github.com/dm3986012/final  
**Páginas:** https://dm3986012.github.io/final/

## Qué incluye
- Nueva página web del portafolio (la del ZIP)
- Evidencias de las **semanas 1 a 8** del repo `portafolio-_final-` registradas en `config.js`
- HTML de actividades, scripts SQL y enlaces a los PDF/infografías del repositorio original

## Cómo publicar
Settings → Pages → Deploy from a branch → main / (root)

## Cómo actualizar
1. Descarga el ZIP completo: `portafolio-final-con-semanas-1-8.zip` (está en los artifacts)
2. Descomprime y sube el contenido a este repositorio (que `index.html` quede en la raíz)
3. O clona y haz `git add . && git commit && git push`
