# Portafolio académico · David Martínez

Sitio estático (HTML, CSS y JavaScript). No necesita backend.

**Repositorio:** https://github.com/dm3986012/final  
**Sitio (GitHub Pages):** https://dm3986012.github.io/final/

## Contenido integrado

Se copiaron e integraron las evidencias de las **semanas 1 a 8** del repositorio anterior (`portafolio-_final-`):

- Páginas de actividad (HTML) de cada semana
- PDFs, SQL y documentos principales (enlazados o incluidos)
- Algunos archivos grandes se sirven desde el repositorio original para no duplicar peso

Todo está registrado en `config.js` → `EVIDENCIAS` y aparece en la sección de actividades del portafolio.

## Estructura
- `index.html` · página principal
- `styles.css` + `futuro.css` · estilos
- `script.js` · actividades, laboratorio SQL, quiz, juego «Encesta», modo editor
- `futuro.js` · partículas, escritura animada, buscador (Ctrl+K), chatbot, modal de proyectos
- `config.js` · datos: correo, proyectos, habilidades, hitos y **archivos públicos**
- `img/foto.jpg` · foto · `cv.pdf` · CV · `evidencias/semana-XX/` · evidencias públicas

## Publicar / actualizar GitHub Pages
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: **main** / folder: **/ (root)**
4. Guarda y espera 1–2 minutos

## Configuración
Edita `config.js` para cambiar correo, proyectos, habilidades y para registrar más evidencias.
